= 備份應用程式捲
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果應用程式磁碟區不屬於任何資源群組，您可以從資源頁面備份該應用程式磁碟區。

*關於此任務*

預設情況下，會建立一致性群組 (CG) 備份。如果您想要建立基於磁碟區的備份，您應該在 _web.config_ 檔案中將 *EnableOracleNdvVolumeBasedBackup* 的值設為 true。

*步驟*

. 在左側導覽窗格中，按一下“*資源*”，然後從清單中選擇 Oracle 資料庫外掛程式。
. 在資源頁面中，從*檢視*清單中選擇*應用程式磁碟區*。
. 點擊 *image:../media/filter_icon.gif["篩選圖標"] *，然後選擇主機名稱和資料庫類型來過濾資源。
+
然後您可以點擊 *image:../media/filter_icon.gif["篩選圖標"] * 關閉篩選窗格。

. 選擇要備份的應用程式磁碟區。
+
將顯示應用程式磁碟區保護頁面。

. 在資源頁面中，執行以下操作：
+
|===
| 對於這個領域... | 這樣做... 


 a| 
對 Snapshot 副本使用自訂名稱格式
 a| 
選取此複選框，然後輸入要用於快照名稱的自訂名稱格式。

例如，customtext__policy_hostname 或 resource_hostname。預設情況下，時間戳記會附加到快照名稱。



 a| 
從備份中排除存檔日誌目標
 a| 
指定您不想備份的存檔日誌檔案的目標。

|===
. 在「策略」頁面中，執行以下步驟：
+
.. 從下拉清單中選擇一個或多個策略。
+

NOTE: 您也可以透過點擊 * 來建立策略image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"]*.



+
在「為選定策略配置計畫」部分中，列出了選定的策略。

+
.. 點選image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"]在要設定計劃的策略的配置計劃列中。
.. 在為政策_policy_name_新增計劃視窗中，配置計劃，然後按一下*確定*。
+
_policy_name_ 是您選擇的政策的名稱。

+
配置的計劃列在「已套用的計劃」欄位中。



. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
+
您也必須指定寄件者和收件者的電子郵件地址以及電子郵件的主題。如果要附加對資源執行的備份作業的報告，請選擇*附加作業報告*。

+

NOTE: 對於電子郵件通知，您必須使用 GUI 或 PowerShell 命令 Set-SmSmtpServer 指定 SMTP 伺服器詳細資訊。

. 查看摘要，然後按一下「*完成*」。
+
進入應用程式捲拓撲頁面。

. 點選*立即備份*。
. 在備份頁面中，執行以下步驟：
+
.. 如果您已對資源套用了多個策略，請從「*策略*」下拉清單中選擇要用於備份的策略。
.. 按一下“*備份*”。


. 透過點選「*監視*」>「*作業*」來監視操作進度。
