= 同一卷上的多個資料庫
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以將所有資料庫放在同一磁碟區上，因為備份策略有一個選項可以設定每個備份的最大資料庫數量（預設值為 100）。

例如，如果同一磁碟區中有 200 個資料庫，則會建立兩個快照，每個快照包含 100 個資料庫。
