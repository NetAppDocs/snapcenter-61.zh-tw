= 新增主機並安裝適用於 Microsoft SQL Server 的SnapCenter外掛程式的先決條件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在新增主機和安裝插件包之前，您必須完成所有要求。

* 如果您正在使用 iSCSI，則 iSCSI 服務必須正在執行。
* 您必須擁有具有本機管理員權限的用戶，且該用戶在遠端主機上具有本機登入權限。
* 如果您在SnapCenter中管理叢集節點，則必須擁有對叢集中所有節點具有管理權限的使用者。
* 您必須擁有在 SQL Server 上具有 sysadmin 權限的使用者。
+
適用於 Microsoft SQL Server 的SnapCenter外掛程式使用 Microsoft VDI 框架，該框架需要係統管理員存取權。

+
https://mskb.pkisolutions.com/kb/2926557["Microsoft 支援文章 2926557：SQL Server VDI 備份與還原作業需要 Sysadmin 權限"^]

* 在 Windows 主機上安裝插件時，如果指定非內建的憑證或使用者屬於本機工作群組用戶，則必須在主機上停用 UAC。
* 如果安裝了SnapManager for Microsoft SQL Server，則必須停止或停用該服務和計畫。
+
如果您打算將備份或複製作業匯入SnapCenter，請不要解除安裝SnapManager for Microsoft SQL Server。

* 主機必須能夠解析為伺服器的完全限定網域名稱 (FQDN)。
+
如果修改了 hosts 檔案以使其可解析，並且在 hosts 檔案中指定了短名稱和 FQDN，則在SnapCenter hosts 檔案中建立一個項目，格式如下：<ip_address> <host_fqdn> <host_name>
