= 為 SQL Server 建立資源組並附加策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源組是一個容器，您可以將想要一起備份和保護的資源新增到其中。資源組可讓您同時備份與給定應用程式相關的所有資料。任何資料保護作業都需要資源組。您還必須將一個或多個策略附加到資源組，以定義要執行的資料保護作業的類型。

您可以單獨保護資源，而無需建立新的資源組。您可以對受保護的資源進行備份。

.關於此任務
* 對於ONTAP 9.12.1 及以下版本、作為復原的一部分從SnapLock Vault 快照建立的克隆將繼承SnapLock Vault 到期時間。儲存管理員應在SnapLock到期後手動清理克隆。
* 不支援將沒有SnapMirror主動同步的新資料庫新增至包含具有SnapMirror主動同步的資源的現有資源組。
* 不支援在SnapMirror主動同步的故障轉移模式下將新資料庫新增至現有資源組。您只能在常規或故障回復狀態下將資源新增至資源組。


.步驟
. 在左側導覽窗格中，按一下“*資源*”，然後從清單中選擇適當的外掛程式。
. 在資源頁面中，從*視圖*清單中選擇*資料庫*。
+

NOTE: 如果您最近為SnapCenter新增了資源，請按一下「刷新資源」以查看新新增的資源。

. 按一下“新建資源組”。
. 在名稱頁面中，執行以下操作：
+
|===
| 對於這個領域... | 這樣做... 


 a| 
Name
 a| 
輸入資源組名稱。


NOTE: 資源組名稱不應超過 250 個字元。



 a| 
標籤
 a| 
輸入一個或多個標籤，以協助您稍後搜尋資源組。例如，如果您將 HR 作為標籤新增至多個資源群組，稍後您可以找到與 HR 標籤關聯的所有資源群組。



 a| 
對 Snapshot 副本使用自訂名稱格式
 a| 
可選：輸入自訂快照名稱和格式。例如，customtext_resourcegroup_policy_hostname 或 resourcegroup_hostname。預設情況下，時間戳記會附加到快照名稱。

|===
. 在資源頁面中，執行以下步驟：
+
.. 從下拉清單中選擇主機名稱、資源類型和 SQL Server 執行個體來過濾資源清單。
+

NOTE: 如果您最近新增了資源，則只有在刷新資源清單後，它們才會出現在可用資源清單中。

.. 若要將資源從「*可用資源*」部分移至「選取資源」部分，請執行下列步驟之一：
+
*** 選擇「自動選擇相同儲存磁碟區上的所有資源」以將同一磁碟區上的所有資源移至「選取資源」部分。
*** 從「*可用資源*」部分中選擇資源，然後按一下右箭頭將其移至「選定資源*」部分。




. 在「策略」頁面中，執行以下步驟：
+
.. 從下拉清單中選擇一個或多個策略。
+

NOTE: 您也可以透過點擊 * 來建立策略image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"]*.

+
在「為選定策略配置計畫」部分中，列出了選定的策略。

.. 在「配置所選策略的計畫」部分中，按一下 *image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"] * 在您想要設定計畫的政策的設定計畫列中。
.. 在「為政策_policy_name_新增計劃」對話方塊中，透過指定開始日期、到期日和頻率來配置計劃，然後按一下「確定」。
+
您必須對策略中列出的每個頻率執行此操作。配置的計劃列在「為選定的策略配置計劃」部分的「已套用的計劃」列中。

.. 選擇 Microsoft SQL Server 排程器。
+
您還必須選擇一個調度程序實例來與調度策略關聯。

+
如果不選擇 Microsoft SQL Server 排程程序，則預設為 Microsoft Windows 排程器。



+
當第三方備份計畫與SnapCenter備份計畫重疊時，不支援第三方備份計畫。您不應修改排程並重新命名在 Windows 排程器或 SQL Server 代理程式中建立的備份作業。

. 在驗證頁面中，執行以下步驟：
+
.. 從*驗證伺服器*下拉清單中選擇驗證伺服器。
+
此清單包括在SnapCenter中新增的所有 SQL Server。您可以選擇多個驗證伺服器（本機主機或遠端主機）。

+

NOTE: 驗證伺服器版本應與託管主資料庫的 SQL 伺服器的版本和版本相符。

.. 按一下「*載入定位器*」以載入SnapMirror和SnapVault卷，對二級儲存執行驗證。
.. 選擇您要設定驗證計劃的策略，然後按一下*image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"] *.
.. 在新增驗證計畫 policy_name 對話方塊中，執行下列操作：
+
|===
| 如果你想... | 這樣做... 


 a| 
備份後運行驗證
 a| 
選擇*備份後執行驗證*。



 a| 
安排驗證
 a| 
選擇*運行計劃驗證*。

|===
.. 按一下“*確定*”。
+
配置的計劃列在「已套用的計劃」欄位中。您可以透過點擊 * 進行檢視和編輯image:../media/edit_icon.gif["用於編輯已配置時間表的圖標"]* 或點選 * 刪除image:../media/delete_icon_for_configuringschedule.gif["刪除圖示"]*.



. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
+
您也必須指定寄件者和收件者的電子郵件地址以及電子郵件的主題。如果要附加對資源組執行的操作的報告，請選擇*附加作業報告*。

+

NOTE: 對於電子郵件通知，您必須使用 GUI 或 PowerShell 命令 Set-SmSmtpServer 指定 SMTP 伺服器詳細資訊。

. 查看摘要，然後按一下「*完成*」。
