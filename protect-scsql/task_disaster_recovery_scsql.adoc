= SnapCenter插件 for SQL Server 的災難復原
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當 SQL Server 的SnapCenter外掛程式關閉時，請使用下列步驟切換到其他 SQL 主機並還原資料。

.開始之前
* 輔助主機應具有與主主機相同的作業系統、應用程式和主機名稱。
* 使用「*新增主機*」或「*修改主機*」頁面將 SQL Server 的SnapCenter外掛程式推送到備用主機。看link:https://docs.netapp.com/us-en/snapcenter/admin/concept_manage_hosts.html["管理主機"]了解更多。


.步驟
. 從「*主機*」頁面中選擇主機來修改並安裝 SQL Server 的SnapCenter插件。
. （可選）將 SQL Server 設定檔的SnapCenter插件從災難復原 (DR) 備份取代到新電腦。
. 從 DR 備份中的 SQL Server 資料夾的SnapCenter插件匯入 Windows 和 SQL 計畫。
