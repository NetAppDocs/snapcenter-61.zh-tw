= 適用於 MySQL 的SnapCenter插件概述
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
適用於 MySQL 資料庫的SnapCenter外掛程式是NetApp SnapCenter software的主機端元件，可實現 MySQL 資料庫的應用程式感知資料保護管理。  MySQL 資料庫外掛程式可自動執行SnapCenter環境中 MySQL 資料庫的備份、復原和複製。

SnapCenter支援單一實例 MySQL 設定。您可以在 Linux 和 Windows 環境中使用 MySQL 資料庫外掛程式。在 Windows 環境中，MySQL 將作為手動資源得到支援。

安裝 MySQL 資料庫外掛程式後，您可以使用具有NetApp SnapMirror技術的SnapCenter在另一個磁碟區上建立備份集的鏡像副本。您也可以使用具有NetApp SnapVault技術的插件來執行磁碟到磁碟的備份複製，以符合標準。

適用於 MySQL 的SnapCenter外掛程式支援ONTAP和 Azure NetApp檔案儲存佈局上的 NFS 和 SAN。

支援VMDK、vVol、RDM虛擬儲存佈局。

不支援符號連結。
