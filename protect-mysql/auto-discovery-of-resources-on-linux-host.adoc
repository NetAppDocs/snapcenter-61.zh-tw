= Linux主機上的資源自動發現
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源是 Linux 主機上由SnapCenter管理的 MySQL 執行個體。安裝SnapCenter Plug-in for MySQL 外掛程式後，該 Linux 主機上的 MySQL 執行個體將自動被發現並顯示在資源頁面中。
