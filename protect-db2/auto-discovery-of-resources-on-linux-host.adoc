= Linux主機上的資源自動發現
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源是 Linux 主機上由SnapCenter管理的 IBM Db2 資料庫和執行個體。安裝適用於 IBM Db2 外掛程式的SnapCenter外掛程式後，該 Linux 主機上所有執行個體的 IBM Db2 資料庫都會自動被發現並顯示在「資源」頁面中。
