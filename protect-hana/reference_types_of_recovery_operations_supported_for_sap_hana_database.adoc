= SAP HANA 資料庫支援的復原操作類型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapCenter可讓您對 SAP HANA 資料庫執行不同類型的復原操作。

* 將資料庫還原到最新狀態
* 將資料庫還原到特定時間點
+
您必須指定恢復的日期和時間。

* 將資料庫還原到特定的資料備份


SnapCenter也為 SAP HANA 資料庫提供了無復原選項。
