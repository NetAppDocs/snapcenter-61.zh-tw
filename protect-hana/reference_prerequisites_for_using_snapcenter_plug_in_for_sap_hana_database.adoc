= 使用適用於 SAP HANA 資料庫的SnapCenter插件的先決條件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在使用適用於 SAP HANA 資料庫的SnapCenter外掛程式之前， SnapCenter管理員必須安裝和設定SnapCenter伺服器並執行先決條件任務。

* 安裝並配置SnapCenter伺服器。
* 登入SnapCenter伺服器。
* 透過新增儲存系統連接和建立憑證（如果適用）來配置SnapCenter環境。
* 在您的 Linux 或 Windows 主機上安裝 Java 11。
+
您必須在主機的環境路徑變數中設定 Java 路徑。

* 如果您想要備份複製，請設定SnapMirror和SnapVault。
* 在將安裝 SAP HANA 資料庫插件的主機上安裝 HDBSQL 用戶端。
+
為您將透過此主機管理的 SAP HANA 節點設定使用者儲存金鑰。

* 對於 SAP HANA 資料庫 2.0SPS05，如果您使用 SAP HANA 資料庫使用者帳戶，請確保您具有下列權限以在SnapCenter Server 中執行備份、還原和複製作業：
+
** 備份管理員
** 目錄閱讀
** 資料庫備份管理員
** 資料庫復原操作員
