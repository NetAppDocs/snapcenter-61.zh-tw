= 還原和還原自動發現的資料庫備份
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用SnapCenter從一個或多個備份還原和還原資料。

.開始之前
* 您必須已備份資源或資源群組。
* 您必須取消目前正在進行的要還原的資源或資源群組的任何備份作業。
* 對於還原前、還原後、安裝和卸載命令，您應該檢查這些命令是否存在於插件主機上可用的命令清單中，路徑如下：
+
** Windows 主機上的預設位置：_C:\Program Files\ NetApp\ SnapCenter\Snapcenter Plug-in Creator\etc\allowed_commands.config_
** Linux 主機上的預設位置：_/opt/ NetApp/snapcenter/scc/etc/allowed_commands.config_





NOTE: 如果命令清單中不存在該命令，則操作將失敗。

.關於此任務
* 無法從SnapCenter還原基於檔案的備份副本。
* 升級到SnapCenter 4.3 後，可以還原在SnapCenter 4.2 中建立的備份，但無法復原。您必須使用SnapCenter外部的 HANA 工作室或 HANA 復原腳本來還原在SnapCenter 4.2 中建立的備份。
* 對於ONTAP 9.12.1 及更早版本、作為復原的一部分從SnapLock Vault 快照建立的克隆將繼承SnapLock Vault 到期時間。儲存管理員應在SnapLock到期後手動清理克隆。
* 對於SnapMirror活動同步恢復操作，您必須從主位置選擇備份。


.步驟
. 在左側導覽窗格中，按一下“*資源*”，然後從清單中選擇適當的外掛程式。
. 在資源頁面中，根據資源類型從*檢視*下拉清單中過濾資源。
+
資源與類型、主機、相關資源群組和政策以及狀態一起顯示。

+

NOTE: 儘管備份可能針對資源群組，但在復原時，您必須選擇要還原的單一資源。

+
如果資源未受保護，則「總體狀態」欄位中顯示「未受保護」。這可能意味著該資源未受到保護，或該資源已被其他使用者備份。

. 選擇資源，或選擇資源組，然後選擇該組中的資源。
+
進入資源拓樸頁面。

. 從「管理副本」檢視中，從主儲存系統或輔助儲存系統（鏡像或保管）中選擇「*備份*」。
. 在主備份表中，選擇要從中還原的備份，然後按一下 *image:../media/restore_icon.gif["恢復圖示"] *.
+
image::../media/restoring_resource.gif[恢復資源]

. 在「復原範圍」頁面中，選擇「*完整資源*」以還原 SAP HANA 資料庫的已設定資料磁碟區。
+

NOTE: 您可以選擇*完整資源*（帶或不帶*卷恢復*）或*租戶資料庫*。

+
當使用者選擇「租用戶資料庫」或「完全還原」選項時， SnapCenter Server 不支援對多個租用戶執行復原作業。您必須使用 HANA 工作室或 HANA python 腳本來執行復原操作。

+
.. 如果您想恢復整個卷，請選擇*卷恢復*。
+
此選項適用於在 NFS 環境中使用SnapCenter 4.3 進行的備份。

+
如果資源包含磁碟區或 qtree，則在這些磁碟區或 qtree 上選擇還原的快照之後拍攝的快照將被刪除，且無法復原。此外，如果任何其他資源託管在相同的磁碟區或 qtree 上，則該資源也會被刪除。當選擇帶有 *Volume Revert* 選項的 *Complete Resource* 進行復原時，這適用。

.. 選擇*租戶資料庫*。
+
此選項僅適用於 MDC 資源。

+
確保在執行復原操作之前停止租戶資料庫。

+
如果選擇「租用戶資料庫」選項，則必須使用 HANA 工作室或使用SnapCenter外部的 HANA 復原腳本來執行復原作業。



. 在「恢復範圍」頁面中，選擇以下選項之一：
+
|===
| 如果你... | 這樣做... 


 a| 
希望恢復到盡可能接近當前時間
 a| 
選擇*恢復到最近的狀態*。對於單一容器資源，指定一個或多個日誌和目錄備份位置。

對於多租用戶資料庫容器 (MDC) 資源，指定一個或多個日誌備份位置和備份目錄位置。

對於 MDC 資源，路徑應包含系統資料庫和租用戶資料庫日誌。



 a| 
想要恢復到指定的時間點
 a| 
選擇*恢復到時間點*。

.. 選擇時區。
+
瀏覽器時區預設填滿。

+
所選時區以及輸入時間將轉換為絕對格林威治標準時間。

.. 輸入日期和時間。例如，HANA Linux 主機位於加州桑尼維爾，而北卡羅來納州羅利的用戶正在將日誌還原到SnapCenter。
+
這兩個地點之間的時差為 3 小時，由於用戶從北卡羅來納州羅利市登錄，因此 GUI 中選擇的預設瀏覽器時區為 GMT-04:00。

+
如果使用者想要恢復到凌晨 5 點，則使用者必須將瀏覽器時區設定為 HANA Linux 主機時區，即 GMT-07:00，並將日期和時間指定為凌晨 5:00

+
對於單一容器資源，指定一個或多個日誌和目錄備份位置。

+
對於 MDC 資源，指定一個或多個日誌備份位置和備份目錄位置。

+
對於 MDC 資源，路徑應包含系統資料庫和租用戶資料庫日誌。





 a| 
想要還原到特定的資料備份
 a| 
選擇*恢復到指定的資料備份*。



 a| 
不想恢復
 a| 
選擇*不恢復*。您必須從 HANA 工作室手動執行復原操作。

|===
+
您只能恢復升級到SnapCenter 4.3 後建立的備份，前提是主機和外掛程式都升級到SnapCenter 4.3，並且選擇用於還原的備份是在資源轉換或發現為自動發現的資源後建立的。

. 在「Pre ops」頁面中，輸入執行復原作業之前要執行的預先復原和卸載命令。
+
卸載命令不適用於自動發現的資源。

. 在 Post ops 頁面中，輸入執行還原作業後要執行的 mount 和 post restore 指令。
+
自動發現的資源無法使用掛載指令。

. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
+
您也必須指定寄件者和收件者的電子郵件地址以及電子郵件的主題。也必須在*設定* > *全域設定*頁面上設定 SMTP。

. 查看摘要，然後按一下「*完成*」。
. 透過點選「*監視*」>「*作業*」來監視操作進度。
