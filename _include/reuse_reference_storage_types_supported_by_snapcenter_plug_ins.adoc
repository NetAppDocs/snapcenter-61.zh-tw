Windows Server 上提供SnapCenter設定和資料保護支援。有關受支援版本的最新信息，請參閱https://imt.netapp.com/matrix/imt.jsp?components=121074;&solution=1257&isHWU&src=IMT["NetApp互通性表工具"^]。
