= Linux主機上的資源自動發現
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
資源是 Linux 主機上由SnapCenter管理的 PostgreSQL 叢集和執行個體。安裝SnapCenter Plug-in for PostgreSQL 外掛程式後，該 Linux 主機上所有執行個體的 PostgreSQL 叢集都會自動被發現並顯示在資源頁面中。
