= 自動發現的 PostgreSQL 支援的復原策略類型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須先定義一個策略，然後才能使用SnapCenter成功執行還原作業。

完整資源復原是自動發現的 PostgreSQL 叢集支援的復原策略。這將恢復資源的所有磁碟區、qtree 和 LUN。
