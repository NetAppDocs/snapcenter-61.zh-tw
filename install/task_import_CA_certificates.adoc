= 匯入 CA 憑證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須使用 Microsoft 管理主控台 (MMC) 將 CA 憑證匯入SnapCenter伺服器和 Windows 主機外掛程式。

.步驟
. 前往 Microsoft 管理主控台 (MMC)，然後按一下 *檔案* > *新增/移除管理單元*。
. 在“新增或刪除管理單元”視窗中，選擇“*證書*”，然後按一下“*新增*”。
. 在憑證管理單元視窗中，選擇「*電腦帳戶*」選項，然後按一下「*完成*」。
. 按一下 *控制台根* > *憑證 - 本機電腦* > *受信任的根憑證授權單位* > *憑證*。
. 右鍵單擊資料夾“受信任的根憑證授權單位”，然後選擇*所有任務*>*匯入*以啟動匯入精靈。
. 完成嚮導，如下圖所示：
+
|===
| 在此精靈視窗中... | 執行以下操作... 


 a| 
導入私鑰
 a| 
選擇選項*是*，匯入私鑰，然後按一下*下一步*。



 a| 
導入文件格式
 a| 
不做任何更改；按一下“下一步”。



 a| 
安全
 a| 
指定匯出憑證要使用的新密碼，然後按一下「下一步」。



 a| 
完成憑證匯入精靈
 a| 
查看摘要，然後按一下「*完成*」開始匯入。

|===
+

NOTE: 匯入憑證時需攜帶私鑰（支援格式為：*.pfx、*.p12、*.p7b）。

. 對「個人」資料夾重複步驟 5。
