= 為SnapCenter啟用 CA 憑證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您應該設定 CA 憑證並為SnapCenter伺服器啟用 CA 憑證驗證。

.開始之前
* 您可以使用 Set-SmCertificateSettings cmdlet 啟用或停用 CA 憑證。
* 您可以使用 Get-SmCertificateSettings cmdlet 顯示SnapCenter伺服器的憑證狀態。


可以透過執行_Get-Help command_name_來取得有關可與 cmdlet 一起使用的參數及其描述的資訊。或者，您可以參考 https://docs.netapp.com/us-en/snapcenter-cmdlets/index.html["SnapCenter軟體 Cmdlet 參考指南"^]。

*步驟*

. 在「設定」頁面中，導覽至「*設定*」>「*全域設定*」>「*CA 憑證設定*」。
. 選擇*啟用憑證驗證*。
. 按一下“*應用*”。


*完成後*

託管主機選項卡主機顯示一個掛鎖，掛鎖的顏色表示SnapCenter伺服器和插件主機之間的連線狀態。

* *image:../media/enable_ca_issues_icon.png["問題圖示"] * 表示沒有啟用或指派給插件主機的 CA 憑證。
* *image:../media/enable_ca_good_icon.png["好圖示"] * 表示 CA 憑證驗證成功。
* *image:../media/enable_ca_failed_icon.png["失敗圖示"] * 表示無法驗證 CA 憑證。
* *image:../media/enable_ca_undefined_icon.png["未定義圖示"] * 表示無法檢索連線資訊。



NOTE: 當狀態為黃色或綠色時，表示資料保護操作已成功完成。
