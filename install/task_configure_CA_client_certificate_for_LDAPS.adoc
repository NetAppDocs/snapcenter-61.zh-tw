= 為 LDAPS 設定 CA 用戶端憑證
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當 Windows Active Directory LDAPS 配置了 CA 憑證時，您應該在SnapCenter伺服器上為 LDAPS 設定 CA 用戶端憑證。

*步驟*

. 前往 Microsoft 管理主控台 (MMC)，然後按一下 *檔案* > *新增/移除管理單元*。
. 在“新增或刪除管理單元”視窗中，選擇“*證書*”，然後按一下“*新增*”。
. 在憑證管理單元視窗中，選擇「*電腦帳戶*」選項，然後按一下「*完成*」。
. 按一下 *控制台根* > *憑證 - 本機電腦* > *受信任的根憑證授權單位* > *憑證*。
. 右鍵單擊資料夾“受信任的根憑證授權單位”，然後選擇*所有任務*>*匯入*以啟動匯入精靈。
. 完成嚮導，如下圖所示：
+
|===
| 在此精靈視窗中... | 執行以下操作... 


 a| 
在嚮導的第二頁
 a| 
按一下“瀏覽”，選擇“根憑證”，然後按一下“下一步”。



 a| 
完成憑證匯入精靈
 a| 
查看摘要，然後按一下「*完成*」開始匯入。

|===
. 對中間證書重複步驟 5 和 6。
