= 刪除克隆
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您發現克隆不再需要，您可以刪除它們。

*關於此任務*

您無法刪除充當其他克隆來源的克隆。

例如，如果生產資料庫是 db1，則資料庫 clone1 是從 db1 的備份克隆的，並且隨後 clone1 受到保護。資料庫 clone2 是從 clone1 的備份克隆而來的。如果您決定刪除 clone1，則必須先刪除 clone2，然後再刪除 clone1。

*步驟*

. 在左側導覽窗格中，按一下“*資源*”，然後從清單中選擇適當的外掛程式。
. 在資源頁面中，從*檢視*下拉清單中選擇資源或資源群組。
. 從清單中選擇資源或資源組。
+
進入資源或資源群組拓撲頁面。

. 從「管理副本」檢視中，從主儲存系統或輔助儲存系統（鏡像或複製）中選擇「*複製*」。
. 選擇克隆，然後按一下image:../media/delete_icon.gif["刪除圖示"]。
+
如果要刪除 SAP HANA 資料庫克隆，請在「刪除克隆」頁面中執行下列操作：

+
.. 在*Pre clone delete*欄位中，輸入在刪除克隆之前應執行的命令。
.. 在 *Unmount* 欄位中，輸入刪除克隆之前卸載克隆的命令。


. 按一下“*確定*”。


*完成後*

有時檔案系統不會被刪除。您必須透過執行以下命令來增加 CLONE_DELETE_DELAY 參數的值：``./sccli Set-SmConfigSettings``


NOTE: CLONE_DELETE_DELAY 參數指定完成應用程式複製刪除後，開始刪除檔案系統之前等待的秒數。

修改參數值後，重新啟動SnapCenter插件Loader(SPL) 服務。
