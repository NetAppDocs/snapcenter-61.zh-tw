= 重新植入被動 Exchange 節點副本
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您需要重新播種副本（例如，當副本損壞時），您可以使用SnapCenter中的重新播種功能重新播種到最新備份。

.開始之前
您必須已經建立了要重新播種的資料庫的備份。

+ 為了避免節點之間滯後，您可以在執行重新播種作業之前建立新的備份，或選擇具有最新備份的主機。

.步驟
. 在左側導覽窗格中，按一下“*資源*”，然後從清單中選擇“*Microsoft Exchange Server 外掛程式*”。
. 在資源頁面中，從視圖清單中選擇適當的選項：
+
|===
| 選項 | 描述 


 a| 
重新植入單一資料庫
 a| 
從視圖清單中選擇*資料庫*。



 a| 
在 DAG 中重新植入資料庫
 a| 
從視圖清單中選擇“*資料庫可用性群組*”。

|===
. 選擇您想要重新播種的資源。
. 在「管理副本」頁面中，按一下「*重新播種*」。
. 從重新播種精靈中的不健康資料庫副本清單中，選擇要重新播種的資料庫副本，然後按一下「下一步」。
. 在「主機」視窗中，選擇要重新播種的備份主機，然後按一下「下一步」。
. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
+
您也必須指定寄件者和收件者的電子郵件地址以及電子郵件的主題。

. 查看摘要，然後按一下「*完成*」。
. 您可以透過展開頁面底部的活動面板來查看作業的狀態。
+

NOTE: 如果被動資料庫副本駐留在非NetApp儲存裝置上，則不支援重新播種作業。
