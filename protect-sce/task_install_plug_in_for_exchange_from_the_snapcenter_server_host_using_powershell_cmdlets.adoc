= 使用 PowerShell cmdlet 從SnapCenter伺服器主機安裝 Exchange 插件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您應該從SnapCenter GUI 安裝 Exchange 插件。如果您不想使用 GUI，則可以在SnapCenter Server 主機或遠端主機上使用 PowerShell cmdlet。

.開始之前
* 必須已安裝並設定SnapCenter伺服器。
* 您必須是主機上的本機管理員或具有管理權限的使用者。
* 您必須是分配有插件、安裝和卸載權限的角色的用戶，例如SnapCenter管理員。
* 在安裝 Exchange 外掛程式之前，您必須已經查看了安裝要求和支援的設定類型。
* 您想要安裝 Exchange 外掛程式的主機必須是 Windows 主機。


.步驟
. 在SnapCenter Server 主機上，使用 _Open-SmConnection_ cmdlet 建立會話，然後輸入您的憑證。
. 使用具有所需參數的 _Add-SmHost_ cmdlet 新增要安裝 Exchange 插件的主機。
+
可以透過執行_Get-Help command_name_來取得有關可與 cmdlet 一起使用的參數及其描述的資訊。或者，您也可以參考 https://docs.netapp.com/us-en/snapcenter-cmdlets/index.html["SnapCenter軟體 Cmdlet 參考指南"^]。

+
主機可以是獨立主機，也可以是 DAG。如果指定 DAG，則需要 _-IsDAG_ 參數。

. 使用帶有所需參數的 _Install-SmHostPackage_ cmdlet 安裝 Exchange 插件。
+
此命令在指定主機上安裝 Exchange 插件，然後向SnapCenter註冊該插件。
