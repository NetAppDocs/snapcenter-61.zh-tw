= 為 SAP HANA 資料庫建立備份策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在使用SnapCenter備份 SAP HANA 資料庫資源之前，您必須為要備份的資源或資源群組建立備份原則。

.步驟
. 在左側導覽窗格中，按一下「*設定*」。
. 在「設定」頁面中，按一下「*策略*」。
. 點選“*新建*”。
. 在名稱頁面中，輸入策略名稱和描述。
. 在「策略類型」頁面中，執行下列步驟：
+
.. 選擇“Azure NetApp Files”作為儲存類型。
.. 如果要執行資料庫的完整性檢查，請選擇「基於檔案」。
.. 如果您想使用快照技術建立備份，請選擇*基於快照*。


. 在快照和備份頁面中，執行下列步驟：
+
.. 選擇計劃備份的頻率。
.. 指定保留設定。
.. 如果要啟用Azure NetApp Files備份，請選擇「啟用備份」並指定保留設定。


. 查看摘要並點擊“完成”。
