= 建立憑證以新增插件主機
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapCenter使用憑證對SnapCenter操作的使用者進行身份驗證。

您應該建立用於安裝SnapCenter插件的憑證以及用於執行資料保護操作的附加憑證。

.步驟
. 在左側導覽窗格中，按一下「*設定*」。
. 在「設定」頁面中，按一下「*憑證*」。
. 點選“*新建*”。
. 在「憑證」頁面中，指定建立憑證所需的下列資訊。
+
|===
| 對於這個領域... | 這樣做... 


 a| 
憑證名稱
 a| 
輸入憑證的名稱。



 a| 
認證模式
 a| 
從下拉清單中選擇身份驗證模式。



 a| 
身份驗證類型
 a| 
選擇 *基於密碼* 或 *基於 SSH 金鑰*（僅適用於 Linux 主機）。



 a| 
使用者名稱
 a| 
指定使用者名稱。



 a| 
密碼
 a| 
如果您選擇了基於密碼的身份驗證，請指定密碼。



 a| 
SSH 私鑰
 a| 
如果您選擇了基於 SSH 金鑰的身份驗證，請指定私鑰。



 a| 
使用 sudo 權限
 a| 
如果您要為非 root 使用者建立憑證，請選取使用 sudo 權限複選框。


NOTE: 這僅適用於 Linux 用戶。

|===
. 按一下“*確定*”。
