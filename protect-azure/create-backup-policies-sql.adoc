= 為 SQL Server 資料庫建立備份策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在使用SnapCenter備份 SQL Server 資源之前為資源或資源群組建立備份策略，也可以在建立資源群組或備份單一資源時建立備份原則。

.步驟
. 在左側導覽窗格中，按一下「*設定*」。
. 在「設定」頁面中，按一下「*策略*」。
. 點選“*新建*”。
. 在名稱頁面中，輸入策略名稱和描述。
. 在「策略類型」頁面中，執行下列步驟：
+
.. 選擇“Azure NetApp Files”作為儲存類型。
.. 選擇備份類型。
+
... 如果要備份資料庫檔案和交易日誌，請選擇「*完整備份和日誌備份*」。
... 如果您只想備份資料庫文件，請選擇“*完整備份*”。
... 如果您只想備份交易日誌，請選擇「*日誌備份*」。
... 如果您想使用其他應用程式備份您的資源，請選擇*僅複製備份*。


.. 在可用性群組設定部分中，執行以下操作：
+
... 如果您只想在副本上備份，請選擇在首選備份副本上備份。
... 選擇主 AG 副本或輔助 AG 副本進行備份。
... 選擇備份優先權。




. 在快照和備份頁面中，執行下列步驟：
+
.. 選擇計劃備份的頻率。
.. 根據所選的備份類型指定保留設定。
.. 如果要啟用Azure NetApp Files備份，請選擇「啟用備份」並指定保留設定。


. 在驗證頁面中，執行以下步驟：
+
.. 在「執行以下備份計畫的驗證」部分中，選擇計畫頻率。
.. 在資料庫一致性檢查選項部分中，執行下列操作：
+
... 選擇*將完整性結構限制為資料庫的實體結構（PHYSICAL_ONLY）*以將完整性檢查限制為資料庫的實體結構，並偵測影響資料庫的頁面撕裂、校驗和失敗以及常見硬體故障。
... 選擇*抑制所有訊息訊息（NO_INFOMSGS）*以抑制所有訊息訊息。
+
預設選擇。

... 選擇*顯示每個物件報告的所有錯誤訊息（ALL_ERRORMSGS）*以顯示每個物件報告的所有錯誤。
... 如果不想檢查非聚集索引，請選擇「*不檢查非聚集索引（NOINDEX）*」。
+
SQL Server 資料庫使用 Microsoft SQL Server 資料庫一致性檢查器 (DBCC) 來檢查資料庫中物件的邏輯和實體完整性。

... 選擇*限制檢查並取得鎖定而不是使用內部資料庫快照副本（TABLOCK）*來限制檢查並取得鎖定而不是使用內部資料庫快照。


.. 在*日誌備份*部分中，選擇*完成後驗證日誌備份*以在完成後驗證日誌備份。
.. 在*驗證腳本設定*部分中，分別輸入在驗證操作之前或之後應執行的腳本或後腳本的路徑和參數。


. 查看摘要並點擊“完成”。
