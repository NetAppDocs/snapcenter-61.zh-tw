= 備份在Azure NetApp Files上執行的 SAP HANA 資料庫
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果資源尚未屬於任何資源群組，您可以從資源頁面備份該資源。

.步驟
. 在左側導覽窗格中，選擇*資源*，然後從清單中選擇適當的外掛程式。
. 在資源頁面中，根據資源類型從*檢視*下拉清單中過濾資源。
. 選擇要備份的資源。
. 在資源頁面中，選擇*使用自訂名稱格式作為 Snapshot 副本*，然後輸入要用於 Snapshot 名稱的自訂名稱格式。
. 在應用程式設定頁面中，執行以下操作：
+
.. 選擇*備份*箭頭來設定其他備份選項。
.. 選擇「*腳本*」箭頭來執行靜默、快照和取消靜默操作的前置和後置命令。
.. 選擇*自訂配置*箭頭，然後輸入使用此資源的所有作業所需的自訂值對。
.. 選擇*Snapshot Copy Tool > SnapCenter without File System Consistency*來建立快照。
+
*檔案系統一致性*選項僅適用於 Windows 主機上執行的應用程式。



. 在「策略」頁面中，執行以下步驟：
+
.. 從下拉清單中選擇一個或多個策略。
.. 選擇 *image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"] * 在您想要設定計畫的政策的設定計畫列中。
.. 在為政策_policy_name_新增計劃對話方塊中，配置計劃，然後選擇*確定*。
+
_policy_name_ 是您選擇的政策的名稱。



. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
+
您也必須指定寄件者和收件者的電子郵件地址以及電子郵件的主題。也必須在*設定* > *全域設定*中配置 SMTP。

. 查看摘要，然後選擇*完成*。
. 選擇*立即備份*。
. 在備份頁面中，執行以下步驟：
+
.. 如果多個策略與資源關聯，請從「*策略*」下拉清單中選擇要用於備份的策略。
+
如果為按需備份選擇的策略與備份計畫相關聯，則按需備份將根據為計畫類型指定的保留設定進行保留。



. 選擇*備份*。
. 透過點選「*監視*」>「*作業*」來監視操作進度。
