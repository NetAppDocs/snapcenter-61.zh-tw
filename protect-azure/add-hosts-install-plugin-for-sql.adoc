= 新增主機並為 SQL Server 資料庫安裝SnapCenter插件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapCenter支援Azure NetApp Files上 SMB 共用上的 SQL 執行個體的資料保護。支援獨立和可用性群組 (AG) 配置。

您必須使用SnapCenter新增主機頁面來新增主機，然後安裝插件包。插件會自動安裝在遠端主機上。

.開始之前
* 您必須是分配有插件安裝和卸載權限的角色的用戶，例如SnapCenter管理員角色。
* 在 Windows 主機上安裝插件時，如果指定非內建的憑證，或使用者屬於本機工作群組用戶，則必須在主機上停用 UAC。


.步驟
. 在左側導覽窗格中，選擇*主機*。
. 驗證頂部的「*託管主機*」標籤是否已選取。
. 選擇“*新增*”。
. 在「主機」頁面中執行以下操作：
+
.. 在主機類型欄位中，選擇主機類型。
.. 在主機名字段中，輸入主機的完全限定網域名稱 (FQDN) 或 IP 位址。
.. 在憑證欄位中，輸入您建立的憑證。


. 在*選擇要安裝的插件*部分中，選擇要安裝的插件。
. （可選）點擊“更多選項”並指定詳細資訊。
. 選擇*提交*。
. 選擇*設定日誌目錄*，在設定主機日誌目錄頁面中輸入主機日誌目錄的SMB路徑，點選*儲存*。
. 點擊*提交*並監控安裝進度。
