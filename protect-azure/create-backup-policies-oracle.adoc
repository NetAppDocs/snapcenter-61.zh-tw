= 為 Oracle 資料庫建立備份策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在使用SnapCenter備份 Oracle 資料庫資源之前，您必須為要備份的資源或資源群組建立備份原則。

.步驟
. 在左側導覽窗格中，按一下「*設定*」。
. 在「設定」頁面中，按一下「*策略*」。
. 從下拉清單中選擇 Oracle 資料庫。
. 點選“*新建*”。
. 在名稱頁面中，輸入策略名稱和描述。
. 在「策略類型」頁面中，執行下列步驟：
+
.. 選擇“Azure NetApp Files”作為儲存類型。
.. 選擇備份類型為線上備份或離線備份。
.. 如果要使用 Oracle Recovery Manager (RMAN) 進行目錄備份，請選擇*使用 Oracle Recovery Manager (RMAN) 進行目錄備份*。
.. 如果要在備份後修剪存檔日誌，請選擇*備份後修剪存檔日誌*。
.. 指定刪除存檔日誌設定。


. 在快照和備份頁面中，執行下列步驟：
+
.. 選擇計劃備份的頻率。
.. 指定保留設定。
.. 如果要啟用Azure NetApp Files備份，請選擇「啟用備份」並指定保留設定。


. 在腳本頁面中，分別輸入要在備份作業之前或之後執行的前置腳本或後置腳本的路徑和參數。
. 在「驗證」頁面中，選擇要執行驗證作業的備份計劃，並分別輸入要在驗證作業之前或之後執行的前置腳本或後置腳本的路徑和參數。
. 查看摘要並點擊“完成”。
