= 備份在Azure NetApp Files上執行的 SQL Server 資料庫
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果資源尚未屬於任何資源群組，您可以從資源頁面備份該資源。

.開始之前
如果 Azure Windows 故障轉移叢集沒有指派叢集 IP 或無法從SnapCenter存取，則應該建立負載平衡器。應配置負載平衡器的 IP 並使其可從SnapCenter伺服器存取。

.步驟
. 在左側導覽窗格中，選擇*資源*，然後從清單中選擇適當的外掛程式。
. 在資源頁面中，從視圖下拉清單中選擇*資料庫*、*實例*或*可用性群組*。
. 在資源頁面中，選擇*使用自訂名稱格式作為 Snapshot 副本*，然後輸入要用於 Snapshot 名稱的自訂名稱格式。
. 在「策略」頁面中，執行以下步驟：
+
.. 從下拉清單中選擇一個或多個策略。
.. 選擇 *image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"] * 在您想要設定計畫的政策的設定計畫列中。
.. 在為政策_policy_name_新增計劃對話方塊中，配置計劃，然後選擇*確定*。
+
_policy_name_ 是您選擇的政策的名稱。

.. 選擇“使用 Microsoft SQL Server 排程器”，然後從與排程原則關聯的“排程器實例”下拉清單中選擇排程器實例。


. 在驗證頁面中，執行以下步驟：
+
.. 選擇驗證伺服器。
.. 選擇您要設定驗證計劃的策略，然後按一下*image:../media/add_policy_from_resourcegroup.gif["從資源群組新增策略"] *.
.. 選擇*備份後執行驗證*或*執行計劃驗證*。
.. 按一下“確定”。


. 在通知頁面中，從*電子郵件首選項*下拉清單中，選擇您想要傳送電子郵件的場景。
. 查看摘要，然後按一下「*完成*」。
. 選擇*立即備份*。
. 在備份頁面中，執行以下步驟：
+
.. 如果多個策略與資源關聯，請從「*策略*」下拉清單中選擇要用於備份的策略。
.. 選擇*備份後驗證*。
.. 選擇*備份*。


. 透過點選「*監視*」>「*作業*」來監視操作進度。
